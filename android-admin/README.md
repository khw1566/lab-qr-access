# 실습실 관리자 (Android)

웹 관리자(`server/public/index.html`)의 관리자 기능을 Java 네이티브 UI로 옮긴 앱입니다. 서버 API(`server/src/index.js`)를 그대로 쓰고, 웹과 같은 학번·비밀번호로 로그인합니다. 관리자 권한이 있는 계정만 들어갈 수 있습니다.

## 화면

| 화면 | 기능 |
| --- | --- |
| 현황 | 대기 건수, 오늘 출입 허용/거부, 단말 연결 상태, 원격 열기, 실시간 보기 |
| 이용 신청 | 승인 대기·승인됨·반려 목록, 지도교수 서명 보기, 승인, 반려·승인 취소(관리자 멘트) |
| 특별 출입 | 상태별 목록, 승인·키 발급, 반려, 승인 취소 |
| 사용자 | 검색·필터·페이지, 정보 수정, 비밀번호 변경, 출입권한 부여, 가입 승인·반려, 정지·해제, 관리자 지정·해제, 가입 정보 삭제 |
| 마스터 QR | 발급(화면용 5분/인쇄용 고정), QR 보기(5초마다 갱신·수동 입력 코드), 재발급, 폐기, 인쇄용 QR 저장·공유·인쇄 |
| 장비 상태 | 장비를 눌러 사용 가능 ↔ 점검 중 전환 |
| 실습실 | 운영 여부, 자동 승인 기준 수정, 실습실 추가 |
| 출입 단말 | 단말 등록과 키 발급(한 번만 표시), 정보 수정, 키 폐기, 원격 열기, 실시간 보기, 실시간 보기 기록 |
| 출입 기록 | 기간·결과·실습실·단말·검색어 조회, 정렬, 페이지 |
| 기능 설정 | 긴급 잠금, 마스터 QR, 문 열림 시간, 실시간 보기·소리 듣기, 신청·가입 설정, 화면 문구 |

실시간 보기는 웹과 같은 WebSocket 형식(`server/src/live.js`)으로 단말 카메라 영상을 받고, 단말 소리 듣기(설정에서 켠 경우)와 폰 마이크로 말하기를 지원합니다. 다른 관리자가 데이터를 바꾸면 `/api/version`을 15초마다 확인해 목록 화면을 다시 불러옵니다.

## 빌드와 설치

JDK 17 이상과 Android SDK(platform 36, build-tools 35)가 필요합니다. `local.properties`에 `sdk.dir`을 적거나 `ANDROID_HOME`을 설정합니다.

```powershell
cd android-admin
.\gradlew.bat assembleDebug
adb install -r app\build\outputs\apk\debug\app-debug.apk
```

릴리스 APK(`assembleRelease`)는 따로 서명 키를 만들기 전까지 디버그 키로 서명됩니다.
